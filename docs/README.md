## 文档维护规则

长期文档按用途存放在 `arch/`、`missions/`、`guides/`、`reports/`、`references/`、`specs/` 和 `adr/`。任务交工单、审查和验证等历史证据保留在工作区根目录的 `issues/`，不把它们当作当前架构结论。

当前实现必须能从代码或验证记录核验；尚未实现的内容标为“规划”或“提案”。修改文档时遵循根目录 [AGENTS.md](../AGENTS.md) 的元数据、版本记录和专项 skill 要求。
